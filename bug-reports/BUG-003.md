# BUG-003 — Registration rejection is not translated in the Russian interface
Environment: isolated local_qa, Russian UI. Evidence reviewed 2026-11-03; original testing 2026-11-02. Exact per-image application build and browser version were not recorded. Source diagnostic baseline is a working copy, not an immutable release.

Severity: Minor. Priority: P2. These are portfolio assessments, not external tracker decisions.

Status: **Fixed; screenshot retest passed for this message**.

Preconditions: Russian signup; free synthetic username and an already occupied synthetic email.

Steps to reproduce:
1. Open signup with Russian selected. Enter a free synthetic username and an already occupied synthetic email.
2. Fill the remaining required fields with valid synthetic data, accept terms and satisfy the approved local test-mode prerequisites.
3. Submit the form and inspect the generic registration error.

Expected result: The generic error is localized into Russian.

Actual result: Before image shows an English error in the Russian interface.

Retest result: The after image shows the equivalent Russian generic error. Other translations and every registration rejection were not exhaustively retested.
