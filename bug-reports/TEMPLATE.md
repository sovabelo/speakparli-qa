# Bug report template

Copy this template for a real finding. It is not an executed test or a defect report.

- **ID and title:**
- **Environment / version / date:**
- **Preconditions:**
- **Steps to reproduce:** numbered actions and synthetic data categories.
- **Expected result:** include the requirement/source when available.
- **Actual result:** observed behavior; include HTTP status only if measured.
- **Severity / Priority:** assessment and reason.
- **Status:** distinguish reported, fixed awaiting retest, partially verified and verified outcomes.
- **Retest:** date/build, method, actual result and remaining uncertainty; use Not Run if no retest took place.
- **Evidence:** relative links to sanitized images/reports.
