# Ограничения тестирования

- Скриншоты фиксируют отдельные наблюдения, а не полное выполнение всех вариантов. Подсказки доступности и maxlength не доказывают серверную валидацию.
- Два серверных позитива TC-005 остаются Blocked: нужны новые уникальные тестовые email. Ранние снимки не превращают позднюю серверную проверку в PASS.
- BUG-002 частично проверен: GET-диагностика прошла, browser POST replay / refresh остаётся INCONCLUSIVE.
- Точные build/версии браузера для каждого снимка и полная матрица браузеров/устройств не зафиксированы. Production не тестировался; полной проверки безопасности нет.
- Региональная ветка исследована на уровне форм; независимо утверждённые требования и live-проверка регионального потока отсутствуют.
- Исторические дефекты описывают прежний анализ. Текущее исправление не подтверждено без новой проверки кода/тестов.

Исходники приложения и инфраструктура приватны. Отчёты и evidence доступны для изучения; воспроизведение требует разрешённого доступа к local_qa, синтетическим фикстурам и перехвату почты. Этот репозиторий не запускает продукт. Русские UI-строки сохранены как часть доказательств.
