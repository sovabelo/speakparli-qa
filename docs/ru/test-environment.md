# Окружение

Изолированный local_qa на Windows: Django, MySQL/Redis/Mailpit в Docker, локальный HTTPS, штатные CSRF и валидация. Письма перехватывались локально. Использован разрешённый тестовый режим антибот-проверки; эффективность production-защиты не оценивалась.

В заметках ручного тестирования указан Firefox; точные версии браузера каждого снимка неизвестны. Серверные отчёты указывают Django 5.2.15 и изменённую рабочую копию, а не неизменяемый релиз для каждого изображения.
